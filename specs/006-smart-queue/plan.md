# Implementation Plan: Smart Waiting Queue

**Branch**: `006-smart-queue` | **Date**: 2026-08-24 | **Spec**: [spec.md](./spec.md)

## Summary

Create a scoped operational queue projection built from waiting queue entries, doctor operational status, priority, and configured slot duration. Queue order is deterministic and recalculated transactionally after relevant changes.

## Technical Context

**Language/Version**: Java 17
**Primary Dependencies**: Spring Boot, JPA, Flyway, PostgreSQL, JUnit/Testcontainers
**Storage**: PostgreSQL; UUIDs, persisted instants, branch IANA timezone
**Testing**: Unit, API, persistence, and concurrency integration tests
**Project Type**: Modular-monolith REST service
**Constraints**: `/api/v1`; trusted server-side staff scope; production fail-closed; no cross-module repository access; PII-minimized audit.

## Constitution Check

PASS: A `queue` module owns API/application/domain/persistence; PostgreSQL controls deterministic concurrent updates; timestamps/timezones are explicit; audits and validation are required.
